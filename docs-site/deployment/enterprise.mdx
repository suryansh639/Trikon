Enterprise is an annual contract, from **$60,000 / year**. See [Pricing](/pricing) for sizing. Start with `trikon-sales@unideploy.com`.

## The perimeter guarantee

```
    Your AWS/GCP account                     Our control plane
    ┌──────────────────────────┐            ┌────────────────────┐
    │  Trikon runner           │◄───────────│  API + dashboard   │
    │  (ECS/EKS, systemd)      │  auth+jobs │  + audit + billing │
    │                          │            │                    │
    │  • clones repo locally   │            │  never sees        │
    │  • runs sandbox locally  │            │  customer source   │
    │  • sends only Verdict    │───verdict─►│                    │
    │    JSON out              │            │                    │
    └──────────────────────────┘            └────────────────────┘
```

Only the `Verdict` JSON crosses your VPC boundary. No source, no diff, no test output, no environment vars.

## Prerequisites

- AWS account (us-east-1 or a region we support) or GCP project
- Terraform 1.6+
- A VPC with two private subnets in different AZs
- IAM/service-account credentials with permission to create ECS/EKS + related resources
- Outbound HTTPS from the private subnets to Trikon control-plane endpoints (allowlisted domains, no wildcards)

## Onboarding (4-8 weeks)

<Steps>
  <Step title="Initial sales + security review">
    First call: use case, scale, compliance requirements. Sales reviews. NDA if needed.
  </Step>
  <Step title="Contract + DPA + security addendum">
    Standard MSA + DPA. Any required custom terms (BAA for HIPAA, etc.) negotiated here.
  </Step>
  <Step title="Terraform module released to your account">
    We provision an S3 bucket in your account, publish the Terraform module + policy-signed runner container image.
  </Step>
  <Step title="You deploy">
    Terraform applies. Runner comes up. Registers with our control plane.
  </Step>
  <Step title="SSO wiring">
    SAML/OIDC configured. Team members log in via your IdP.
  </Step>
  <Step title="Pilot period">
    2-4 weeks of monitored operation on a subset of repos. Weekly review calls.
  </Step>
  <Step title="Rollout">
    Onboard remaining repos. Managed policy tuning included.
  </Step>
</Steps>
