title: "trikon mcp serve"

---

Runs the Trikon MCP server so any MCP-aware AI agent (Claude Code, Cursor, Codex, custom) can invoke `verify_change`.

## Usage

```bash
trikon mcp serve [OPTIONS]
```

## Options

| Option | Default | Description |
| --- | --- | --- |
| `--stdio` | off | Communicate over stdio (for editor-embedded agents) |
| `--port <n>` | `4801` | TCP port (only used when `--stdio` is off) |
| `--host <addr>` | `127.0.0.1` | Bind address |
| `--sandbox <backend>` | `docker` | Sandbox backend for verification runs |

## Examples

<CodeGroup>
```bash Stdio (Claude Code, Cursor)
trikon mcp serve --stdio
```
```bash TCP (custom clients)
trikon mcp serve --port 4801
```
```bash Fast local (no sandbox)
trikon mcp serve --stdio --sandbox=none
```
</CodeGroup>
